## 一、结论先行：这应用没有语言开关

在 `web-dist`（110 个 JS，9 MB）全量取证：

| 检索项 | 命中 | 含义 |
|---|---|---|
| `useTranslation` / `i18next` / `translations` / 消息目录 | **0** | 没有任何 i18n 框架 |
| `navigator.language` | 7 | 只用于 `Intl` 数字/日期格式化 |
| `locale` | 298 | 几乎全是 `localeCompare()` 排序 |
| `index.html` | — | `lang="en" translate="no"` + `<meta name="google" content="notranslate">`，注释明确写"整页自动翻译会让 React 崩（facebook/react#11538）" |

所以没有"切换语言"这条路：只能①替换字符串（构建期）②运行时替换文本节点。**本方案两层都做了。**

## 二、两层架构（v2：英文基线 + 运行时翻译 + 真开关）

```
原始包保持英文（不重打包 chunk）
   └─ index.html 注入一个 <script src="./assets/zh-runtime.js">（唯一改动）
        ├─ 词典  assets/zh-cn.json（1957 条，改完 F5 即生效）
        ├─ 翻译  文本节点 + placeholder/title/aria-label/alt
        ├─ 还原  记录被改过的节点/属性 → 切英文时逐字段精确还原
        └─ 开关  右下角常驻「🌐 语言」按钮 → 中文（简体） / English（勾选态，与 Claude 的语言选择一致）
```

**为什么改成这样**：v1 把中文直接写进 chunk 后，英文模式无法还原、每个新页面都要靠补丁覆盖；新建项目/新面板一旦是新 chunk 就会掉英文。
v2 只依赖运行时层，**任何新页面、新项目、新面板都由同一套词典覆盖**（MutationObserver + 轮询补扫），且 EN 模式是 100% 真英文。

| 改动点 | v1（构建期补丁） | v2（运行时 + 开关） |
|---|---|---|
| 英文模式 | 无法还原（chunk 已被改成中文） | ✅ 精确还原（记录原文） |
| 新建项目/新面板 | 依赖 chunk 是否被打过 | ✅ 自动覆盖 |
| 加词 | 要重跑 apply + 硬刷新 | ✅ 改词典 + F5 |
| React 风险 | 改模块字面量（曾触发 #321） | ✅ 不碰模块，结构上安全 |
| 首屏 | 直接中文 | 有极短英文闪烁（词典本地读取，通常 <100ms） |

`apply.cjs`（构建期补丁）保留但**默认不用**；只在想彻底去掉闪烁时才跑，跑完记得 `node build-runtime.cjs` 把 script 标签插回去。

## 三、踩过的坑（重要）

| 坑 | 现象 | 原因 | 修法 |
|---|---|---|---|
| 给模块 import 加 `?locale=zh-CN-v1` | 设置里点"记忆/权限/存储"→ **React error #321 = Invalid hook call** | 同一模块出现两个 URL，懒加载面板把 React 加载两份 | **永不改 import、永不加查询参数**；缓存用硬刷新（Ctrl+Shift+R）解决 |
| 只改 `children` 等属性位 | 面板标题中文、正文英文 | 大量文案在 `hint/sub/benefit/detail` 等非白名单键里 | 扩展 UI 键集合（apply v4） |
| 只靠 MutationObserver | 首屏后 React 批量挂载的文案漏翻 | 某些渲染时序下 observer 回调不触发 | 加**轮询补扫**（前 60 秒每 1.5 秒，之后每 10 秒） |
| 只翻整句 | aria-label（"Search"/"New project"）仍英文 | 属性不在文本节点里 | 运行时层增加属性替换（实测一次扫描处理 130 个属性） |

## 四、加词流程（改完 F5 即生效，不必重打包、不必重启）

```powershell
cd <本仓库目录>

# 1) 往批次文件里加条目（键 = 英文原文，值 = 中文；碎片词请用 trim 后的形式）
#    zh-CN-0.1.70.json / zh-cn-longtail.json / zh-cn-b2..b9.json 任意一个都行

# 2) 只更新运行时词典（够日常用，页面 F5 生效）
node build-runtime.cjs

# 3) 想让首屏也是中文（可选，会重打 chunk；之后窗口需 Ctrl+Shift+R）
node apply.cjs ; node build-runtime.cjs
```

**注意顺序**：`apply.cjs` 会从英文原文重写 `index.html`，`build-runtime.cjs` 负责把 `<script src="./assets/zh-runtime.js" defer>` 再插回去 —— 所以**先 apply 后 build-runtime**。

批量体检：

```powershell
node extract4.cjs 80        # 在英文原文上统计还没翻的 UI 文案（top 80）
python verify_zh.py         # 开一个干净窗口 + 硬刷新，量出主界面还剩多少英文
python probe_panel2.py      # 自动进「自定义/设置」面板，逐面板量剩余英文
```
